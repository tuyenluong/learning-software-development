# Backend engineer job market reports

Weekly Backend Engineer job market reports (Go · Java Spring Boot · Quarkus · Kafka · RabbitMQ), one per Friday, named `backend-job-market-YYYY-MM-DD.md`. Each uses the same format as the QE reports in [../qa-engineer/](../qa-engineer/): top skills, "What changed this week", then sections 0–10, an "Earlier data" section (the first report only) and caveats. Only backend reports go in this folder.

Newest first:

- [backend-job-market-2026-10-30.md](backend-job-market-2026-10-30.md): first run and series baseline, 30 Oct 2026 (compared against the backend parts of the 21 Oct baseline and the 28 Oct report; those backend figures are kept in its Earlier data section)

Reports use aggregate figures only (skill counts, seniority, salary ranges where stated), never individual emails or contact details.
