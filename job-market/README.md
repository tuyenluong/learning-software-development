# Job market reports

QE / automation testing and backend engineering job market research. Only reports go in this folder, one subfolder per role; teaching notes live in [learning-material/](../learning-material/) (see the [main README](../README.md)).

- [qa-engineer/](qa-engineer/): QA / QE automation reports. Baseline [qe-job-market-2026.md](qa-engineer/qe-job-market-2026.md) (21 Oct 2026), then weekly reports every Friday night named `job-market-YYYY-MM-DD.md`, each with a "What changed this week" section. Listed in [qa-engineer/README.md](qa-engineer/README.md).
- [backend-engineer/](backend-engineer/): weekly Backend Engineer reports (Go, Spring Boot, Quarkus, Kafka, RabbitMQ), named `backend-job-market-YYYY-MM-DD.md`, same format. Listed newest first in [backend-engineer/README.md](backend-engineer/README.md).

Newest reports of both kinds are also listed first in [INDEX.md](../INDEX.md).

Reports use aggregate figures only (skill counts, seniority, salary ranges where stated), never individual alert emails or postings' contact details.
